# Tic Tac Toe

A simple browser-based Tic Tac Toe game built using **HTML, CSS, and JavaScript**. The game has a 3×3 board, alternates between X and O turns, checks for winning combinations, detects draws, and lets players restart the game.

## Features

- 3×3 Tic Tac Toe board
- Turn switching between **X (AI)** and **O (Ajit)** labels
- Win detection for rows, columns, and diagonals
- Draw detection when all cells are filled
- Disabled board after a win
- Reset button to start a new game
- Simple, clean blue-and-white interface

> Note: Despite the current “AI” label, the game does not yet contain an AI opponent. Players take turns clicking the board.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Click any empty square to make a move.
4. Use **Reset Game** to play again.

## Gameplay

- **X** starts first.
- Players alternate between X and O.
- The first player to make three matching marks in a row, column, or diagonal wins.
- If all nine cells are filled and nobody wins, the game ends in a draw.
